# Stonly

> Stonly is a knowledge management and customer self-service platform for creating interactive step-by-step guides, decision trees, and structured knowledge content. It powers customer self-service and agent-assisted support with a knowledge base, an embeddable widget, AI chatbots and agent assist, and process automation, and integrates with tools like Zendesk, Salesforce, ServiceNow, Freshdesk, Zapier, Segment and HubSpot. Developers embed guides in native apps via first-party iOS, Android and React Native SDKs (plus a CLI), and manage content through Stonly's HTTP API.

## SDKs & CLI
- [iOS SDK](https://github.com/StonlyHQ/stonly-ios-sdk): CocoaPods `Stonly` (Objective-C).
- [Android SDK](https://github.com/StonlyHQ/stonly-android-sdk): JitPack `com.github.StonlyHQ:stonly-android-sdk`.
- [React Native SDK](https://www.npmjs.com/package/stonly-react-native): npm `stonly-react-native`.
- [CLI](https://www.npmjs.com/package/stonly-cli): npm `stonly-cli` / `stonly-sdk-cli` — install and wire the mobile SDKs.
